## Escapa de la nave espacial

Eres un este juego, un astronauta tiene que escapar de su nave después de que un meteorito la haya dañado. Para conseguirlo, tendrás que resolver tres acertijos antes de quedarte sin oxígeno. Tienes 3 intentos para cada prueba.
